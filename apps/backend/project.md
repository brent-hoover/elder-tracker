# Elder Tracker

## Summary

Elder Tracker is an application for sharing status updates by all the caregivers of a particular elder person.

### Basic Actions

Users are assigned an elder person, who they can login in create a status update of various types:
1. Doctor visit
2. Accident
3. Change in behavior
4. Change in symptoms
5. General Observation

Once they log in to the app they can choose which elder person, choose which entry type and then they can make a free
text entry describing the event. The event is then logged with the date/time is was entered. 

All the users who are assigned to a particular elder person can see all the entries in the log. Users can filter by
date or by who made the entry.

This should be a monorepo which should feature a NestJS backend and a Vue frontend.
